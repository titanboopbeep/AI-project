# Libraries and Technologies

This document explains every Python dependency used by Mars Surface AI, plus the Python standard-library module used by the application.

## Python dependencies

| Library / package | What it does | Where it is used |
|---|---|---|
| **Streamlit** (`streamlit`) | Creates the web application interface and handles image/model uploads, buttons, status messages, tables, and CSV downloads. | User interface and application flow in `app.py`. |
| **Pandas** (`pandas`) | Loads and manipulates tabular data, including Orange's embedding CSV, training labels, and prediction results. | Reading training data and preparing downloadable result tables. |
| **NumPy** (`numpy`) | Provides numerical arrays and vector operations. It helps validate and pass numerical image embeddings to the classifier. | Embedding arrays and numeric data handling. |
| **Scikit-learn** (`scikit-learn`) | Provides the Random Forest classifier, train/test splitting, and evaluation metrics such as accuracy, classification report, and confusion matrix. | Training, evaluating, and predicting Rocky/Smooth classes. |
| **Joblib** (`joblib`) | Serializes and reloads the trained scikit-learn model bundle, including its expected feature-column information. | Saving and loading `.joblib` model files. Only load model files from trusted sources. |
| **Pillow** (`Pillow`, imported as `PIL`) | Opens uploaded JPG/PNG images and converts them into a consistent RGB image representation before feature extraction. | Image loading and preparation. |
| **PyTorch** (`torch`) | Runs the neural network for image feature extraction and provides inference-mode and tensor operations. | Running SqueezeNet on uploaded images. |
| **Torchvision** (`torchvision`) | Supplies the pretrained SqueezeNet 1.1 architecture, ImageNet weights, and image preprocessing transforms. | Converting each uploaded image into a 1,000-value feature vector. |

## Python standard-library module

| Module | What it does | Where it is used |
|---|---|---|
| **`io`** | Provides in-memory byte streams. | Opens uploaded image bytes without first saving them as files. |

`io` is included with Python and does not need to be listed in `requirements.txt`.

## How the components work together

### Training

1. **Orange Data Mining** (an external desktop application, not a Python dependency in this repository) uses its Image Embedding widget with SqueezeNet to generate image features.
2. **Pandas and NumPy** read and prepare the labelled embedding CSV.
3. **Scikit-learn** trains and evaluates the Random Forest classifier.
4. **Joblib** saves the trained model bundle as a `.joblib` file.

### Prediction from uploaded images

1. **Streamlit** receives the uploaded image.
2. **Pillow** opens the image and converts it to RGB.
3. **Torchvision** applies the SqueezeNet preprocessing.
4. **PyTorch** runs SqueezeNet and extracts the image feature vector.
5. **Scikit-learn** uses the trained Random Forest to predict `Rocky` or `Smooth`.
6. **Pandas and Streamlit** display the results and provide a CSV download.

## `requirements.txt`

The third-party Python packages are listed in `requirements.txt`:

```text
streamlit
pandas
numpy
scikit-learn
joblib
Pillow
torch
torchvision
```

Install them from the project root with:

```bash
python -m pip install -r requirements.txt
```

## Important compatibility limitation

The training embeddings were generated by Orange's Image Embedding widget, while direct-image inference in this app currently uses `torchvision` SqueezeNet 1.1 with ImageNet weights and torchvision's standard preprocessing.

Matching output dimensions (1,000 values) does **not** prove the feature vectors are equivalent. The exact model version, selected output layer, preprocessing, and feature ordering must match. Compare vectors generated for the same image in Orange and this app before relying on predictions. If they do not match, update the inference extractor or regenerate the training embeddings using the exact same extraction pipeline.
